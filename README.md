Pastimes Thrift Store

Overview

Pastimes Thrift Store is a full-stack e-commerce web application developed using PHP, MySQL, HTML, and CSS. The platform enables users to buy and sell branded pre-owned clothing through a secure online marketplace.

 Features

* User Registration and Login
* Seller Registration and Approval Workflow
* Administrator Registration and Management
* Product Catalogue
* Shopping Cart Functionality
* Checkout and Order Processing
* Seller Dashboard
* Admin Dashboard
* Inventory Management
* Session-Based Authentication
* Password Hashing (BCRYPT)
* MySQL Database Integration

Technologies Used

* PHP
* MySQL
* HTML
* CSS
* SQL

 Project Highlights

* Designed and implemented database-driven functionality
* Developed authentication and authorization workflows
* Implemented CRUD operations for products and users
* Built shopping cart and checkout functionality
* Integrated session management and secure password storage

Installation

1. Import `myClothingStore.sql` into MySQL.
2. Update database credentials in `DBConn.php`.
3. Place project files in your web server directory.
4. Start Apache and MySQL.
5. Open the application through localhost.
